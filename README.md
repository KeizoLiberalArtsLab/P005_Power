# パワー測定ラボ — 荷物を5 m運ぼう

荷物のイラストをドラッグして5 m運ぶ時間を測り、仕事率（平均パワー）を求めるブラウザアプリです。

## アプリを起動する

**[▶ パワー測定ラボを開く](https://keizoliberalartslab.github.io/P005_Power/)**

配布・共有用URL：https://keizoliberalartslab.github.io/P005_Power/

上のリンクをブラウザで開くと利用できます。インストールやGitHubへのログインは不要です。ほかの方に使ってもらう場合は、このURLを共有してください。

## 使い方

上の「パワー測定ラボを開く」リンクからアプリを起動してください。荷物のイラストをマウスまたはタッチでつかみ、右へドラッグすると、動き始めた瞬間から計測します。荷物の中心がスタート線から5 m先のゴール位置に達すると計測を止めます。「もう一度」で初期位置に戻せます。

「5秒」「2.5秒」「1秒」ボタンを押すと、それぞれ指定した時間で荷物が5 m進むアニメーションを再生し、時間と平均パワーを表示します。

## 計算

進行方向に一定の力50 Nが5 mの全区間で加わると仮定します。

- 仕事：50 N × 5 m = 250 J
- 平均パワー：250 J ÷ 移動にかかった時間（秒）

荷物の移動はユーザーのドラッグ操作または時間指定アニメーションで決まります。加速度や摩擦などの力学モデルは扱いません。
