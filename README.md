# パワー測定ラボ — 荷物を5 m運ぼう

荷物のイラストをドラッグして5 m運ぶ時間を測り、仕事率（平均パワー）を求めるブラウザアプリです。

## 配布・起動用URL

[https://keizoliberalartslab.github.io/P005_Power/](https://keizoliberalartslab.github.io/P005_Power/)

## 起動

`index.html` をブラウザで開いてください。インストールや外部ライブラリは不要です。

## 使い方

荷物のイラストをマウスまたはタッチでつかみ、右へドラッグします。荷物が実際に動き始めた瞬間に計測を開始します。途中で離して再度つかむこともできます。荷物の左端がスタート線から5 m先のゴール線に着くと時間を止め、仕事と平均パワーを表示します。「もう一度」で再計測できます。

## 計算

進行方向に一定の力50 Nが5 mの全区間で加わると仮定します。

- 仕事：50 N × 5 m = 250 J
- 平均パワー：250 J ÷ 到達時間（秒）

荷物の移動はユーザーのドラッグ操作で決まります。加速度や摩擦などの力学モデルは扱いません。
