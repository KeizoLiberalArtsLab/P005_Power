# パワー測定ラボ — 荷物を5 m運ぼう

荷物のイラストをドラッグして5 m運ぶ時間を測り、仕事率（平均パワー）を求めるブラウザアプリです。

## アプリを起動する

**[▶ パワー測定ラボを開く](https://keizoliberalartslab.github.io/P005_Power/)**

配布・共有用URL：https://keizoliberalartslab.github.io/P005_Power/

上のリンクをブラウザで開くと利用できます。インストールやGitHubへのログインは不要です。ほかの方に使ってもらう場合は、このURLを共有してください。

## 使い方

上の「パワー測定ラボを開く」リンクからアプリを起動してください。

ダウンロードして使う場合は、`index.html` をブラウザで開いてください。インストールやビルドは不要です。

荷物のイラストをマウスまたはタッチでつかみ、右へドラッグします。荷物が実際に動き始めた瞬間に計測を開始します。途中で離して再度つかむこともできます。荷物の中心がスタート線から5 m先のゴール位置に達すると時間を止め、仕事と平均パワーを表示します。「もう一度」で再計測できます。

## 計算

進行方向に一定の力50 Nが5 mの全区間で加わると仮定します。

- 仕事：50 N × 5 m = 250 J
- 平均パワー：250 J ÷ 到達時間（秒）

荷物の移動はユーザーのドラッグ操作で決まります。加速度や摩擦などの力学モデルは扱いません。
